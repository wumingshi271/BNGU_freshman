# OpenCV最小框选与多边形拟合（选做题）

该项目运用颜色分割，实现了下面的蓝牙耳机在摄像头中给框选出来

## 实现思路

通过提取粉色的hsv掩码，将图片中的黑色色单独提取出来

掩码如下所示：

| hsv | 下界 | 上界 |
| :-: | :--: | :--: |
|  h  |  0  | 255 |
|  s  |  0  | 255 |
|  v  |  0  |  60  |

然后将视频里的蓝牙耳机框选出来
